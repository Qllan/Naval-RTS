# Девятка — полный бэклог

Весь объём работ по GDD v2.0 плюс то, чего в GDD нет, но без чего игра не выйдет: арт, звук, UI, инструменты, QA, выпуск.

**Приоритеты:**
- **P0** — вертикальный срез: без этого нельзя проверить игру
- **P1** — версия 1.0 / Early Access
- **P2** — после релиза

Ссылки вида «GDD §2.2» ведут на разделы дизайн-документа. Статус «✅ прототип» значит, что в pygame есть черновая версия.
